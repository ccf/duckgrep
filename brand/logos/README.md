The duckgrep marks, all pure paths (no fonts needed). Inks are fixed per file — an `<img>` cannot inherit colour — so pick the file by the ground.

- `duckgrep-mark.svg` — the primary mark: `duck-yellow` d on an `ink` (#0d0d0d) tile, eye in #0d0d0d. Favicon, avatar, GitHub org, social cards. Any ground.
- `duckgrep-mark-yellow.svg` — #0d0d0d d on a `duck-yellow` tile, eye in yellow. For dark or photographic grounds.
- `duckgrep-glyph-ink.svg` — the bare duck-d in #0d0d0d with a transparent eye. Light grounds only; inline in text or small UI.
- `duckgrep-glyph-yellow.svg` — the bare duck-d in #fff100 with a transparent eye. Dark grounds only.
- `dgrep-wordmark-light.svg` — duck-d + "grep" (JetBrains Mono ExtraBold, outlined), all #0d0d0d, transparent eye. Light grounds.
- `dgrep-wordmark-dark.svg` — yellow duck-d + "grep" in #f2f2f2. Dark grounds.
- `duckgrep-lockup-light.svg` — ink tile + "duckgrep" in #0d0d0d (Hanken Grotesk Bold, outlined). Site header and README on light grounds.
- `duckgrep-lockup-dark.svg` — yellow tile + "duckgrep" in #f2f2f2. Dark grounds.
